# IntegratedTech (集成科技)

[![NeoForge](https://img.shields.io/badge/Minecraft-26.3-orange)](https://neoforged.net/)
[![License: LGPL v3](https://img.shields.io/badge/License-LGPL_v3-blue.svg)](LICENSE)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.2-purple.svg)](https://kotlinlang.org/)

告別格雷科技（GregTech）式的微合成「坐牢」體驗！
**IntegratedTech** 是一個專注於**實體傳送帶、物理注射機制**，以及透過**低電壓（LV）工控電腦統一調度**的現代自動化流水線模組。

## ✨ 核心特色
- ⚙️ **無縫過渡**：從蒸汽時代的純機械齒輪/滑道，平滑過渡到電力時代。
- 📦 **可視化物理物流**：物品在傳送帶上實體推進，具備防卡料（Flow Control）背壓機制，拒絕黑盒子。
- 💻 **中樞工控機（Machine Computer）**：解鎖 LV 即刻擁有一站式調度中心，告別繁瑣紅石線與模式晶片。
- 🚀 **極致效能**：基於 Minecraft 26.3 NeoForge 能力系統（Capabilities），上百格傳送帶流暢不卡服。
